# mnist-from-scratch
使用 Python 和 NumPy 从零实现 MNIST 手写数字识别

## 项目简介

MNIST 是一个经典的手写数字图像数据集。每张图片都是 28×28 像素的灰度图，并带有 0～9 中的一个正确标签。本项目会把每张图片展开成 784 个像素值，让神经网络根据这些像素判断图片中的数字。

## 项目目标

这个项目的重点不仅是得到预测结果，还要理解神经网络内部的主要计算。我们将只使用 Python 和 NumPy 实现一个两层全连接神经网络，目标是在 MNIST 测试集上达到约 95% 或更高的准确率。

完成项目后，我希望能够：

- 解释一张 28×28 图片怎样变成 784 个输入值；
- 说明神经网络如何根据输入计算 0～9 的预测结果；
- 理解前向传播、反向传播和梯度下降的作用；
- 保存训练好的模型，并使用模型识别新的手写数字。

## 开发计划

1. **认识数据**：下载并读取 MNIST，查看图片、标签和数据形状，理解训练集与测试集的区别。
2. **实现神经网络**：使用 NumPy 编写全连接层、ReLU、softmax、交叉熵、前向传播和反向传播。
3. **训练模型**：使用梯度下降更新参数，记录损失和准确率，并调整重要训练参数。
4. **评估和完善**：在测试集上计算准确率与混淆矩阵，支持保存和加载模型，并添加自动化测试。
5. **继续扩展**：尝试使用 C 语言加载训练好的权重并完成推理，为后续学习 `llama2.c` 做准备。
